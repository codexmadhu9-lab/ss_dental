# Sanjeevi Digital Health

Advanced Hospital Website Prompt

Create a premium, modern, highly interactive hospital website for “SANJEEVI HOSPITAL”.

Use the provided SANJEEVI HOSPITAL logo as the primary brand identity throughout the website. The logo features a heart/family medical concept and must remain visually consistent with the website branding.

Brand & Visual Identity

Use the logo's color palette as the foundation:

 Primary: Soft Lavender / Light Purple

 Secondary: Elegant Purple

 Background: Pure White

 Supporting shades: very light lavender, subtle grey, and white

 Avoid overly dark purple or excessive colorful elements

 Overall appearance should feel premium, trustworthy, calm, compassionate, clean and medical

Use subtle gradients such as:
#E9D5FF → #C084FC → #8B5CF6

Typography should be modern, elegant and highly readable. Use a combination of a sophisticated heading font and clean sans-serif body font.

Design Direction

Take inspiration from the structure and healthcare experience of Motherly Hospital, but DO NOT copy its design, text, branding, images, layout, or visual identity. Create an original SANJEEVI HOSPITAL experience.

The website must look like a high-end private hospital website, not a generic template.
